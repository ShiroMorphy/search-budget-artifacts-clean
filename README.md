# Search-Budget Artifacts in Gaussian Continuous Causal Emergence

Clean reproducibility package for the paper

> Felipe Mora, *Search-Budget Artifacts in Gaussian Continuous Causal Emergence:
> Fixed-Step Riemannian Optimization Can Manufacture Apparent Scale Dependence*.

This public package contains the software, reproduction runners, figures,
archived numerical outputs, data retrieval tools, and Lean formalization. The
manuscript, cover letter, and journal highlights are intentionally excluded;
they are submission materials rather than software or reproducibility
dependencies.

The current public release is
[GitHub release v1.0.0](https://github.com/ShiroMorphy/search-budget-artifacts-clean/releases/tag/v1.0.0).
This clean v1.0.0 release aligns the repository with the final manuscript
submission; its reproducibility inputs and numerical outputs are unchanged.
The full version history is documented in [RELEASE_NOTES.md](RELEASE_NOTES.md).

## Reproducing the results

Install the dependencies with pip install -r requirements.txt, retrieve the
non-redistributed portfolio data with python3 data/download_ff30.py, and run
./reproduce_paper1.sh.

The pipeline regenerates the numerical outputs and the four publication
figures. A full run takes roughly one hour on two cores.

## Formal verification

The Lean development is checked against mathlib with no unproved assumptions.
It proves that the projected state is autonomous for every initial condition if
and only if the residual operator W A (I - Wᵀ W) vanishes, and proves a related
Rayleigh Ritz compression inequality. The singular-value contraction argument
used in Proposition 1 and the uniform pullback-smoothness bound are not
formalized; formalization/README.md documents the exact scope.
